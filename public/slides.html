สไลด์ 1 · นิยาม

Prompt คืออะไร ทำไมถึงสำคัญ

  • Prompt = ข้อความ/คำสั่งที่เราป้อนให้ AI เพื่อบอกว่าต้องการผลลัพธ์แบบไหน
  • อาจเป็นคำถาม คำสั่ง หรือคำอธิบาย — สั้นหรือยาวก็ได้
  • สำคัญเพราะเป็นตัว ชี้นำทิศทางและคุณภาพผลลัพธ์ — prompt ชัด = คำตอบตรง
จำ: คุณภาพของคำตอบ เริ่มจากคุณภาพของคำถามเสมอ
สไลด์ 2 · พื้นฐาน

AI เข้าใจภาษาของเราได้อย่างไร

  • AI ถูกฝึกด้วยข้อมูลมหาศาลบนอินเทอร์เน็ต — บทความ บทสนทนา บริบทต่าง ๆ
  • มันตีความประโยคจาก วิธีพิมพ์ การใช้คำ บริบท และความเชื่อมโยงของเนื้อหา
  • ยิ่งเราให้บริบทชัด ความ "เดา" ของ AI ยิ่งน้อยลง
AI ไม่อ่านใจ — มันอ่าน "บริบท" ที่เราให้
สไลด์ 3 · เทคนิคหลัก

Shot Prompting: Zero / One / Few-shot

  • Zero-shot — ถามโดยไม่ให้ข้อมูล/ตัวอย่างเลย → คำตอบกว้าง บางครั้งไม่ตรง
  • One-shot — ให้ตัวอย่าง 1 ตัวอย่าง
  • Few-shot — ให้ข้อมูล รายละเอียด หรือตัวอย่างหลายชุด → คำตอบตรงเป้าและคุมได้
สูตรของการบ้านชิ้นนี้: zero-shot → ดูผล → ถามต่อ → few-shot
สไลด์ 4 · โครงสร้าง

เทคนิค Role – Goal – Context (RGC)

  • Role — กำหนดบทบาท: "คุณเป็นผู้ช่วยสอนรายวิชา GenAI…"
  • Goal — ระบุเป้าหมาย: "สร้างสไลด์ทบทวน 10 หน้าสำหรับนักศึกษาก่อนสอบ"
  • Context — ให้บริบท: ผู้อ่านคือใคร รูปแบบผลลัพธ์ ข้อจำกัด
ครบ 3 ส่วน = Prompt มีโครง ไม่ล่องลอย
สไลด์ 5 · เทคนิคเสริม

Priming & Chain of Thought

  • Prompt Priming — เตรียมบริบทก่อนถาม เช่น ให้ AI อ่านเอกสารก่อนสั่งสรุป
  • Chain of Thought — ขอให้คิดทีละขั้น อธิบายเหตุผล ยกตัวอย่าง
  • ใช้คู่กับ Summarising Prompts: กำหนดความยาว กลุ่มเป้าหมาย จุดเน้น
"คิดทีละขั้น" ช่วยลดความผิดพลาดของโจทย์ซับซ้อน
สไลด์ 6 · เทคนิคขั้นสูง

Prompt Inception Technique

  • ให้ AI ช่วยเขียน prompt ตามโครงสร้างที่เราต้องการ
  • ตัวอย่าง: "ช่วยเขียน prompt ที่ดีที่สุดสำหรับหัวข้อ สรุปข่าวการศึกษาไทยประจำสัปดาห์ ให้เหมาะกับนักศึกษา"
  • แล้วนำ prompt ที่ได้ไปถามต่อ — AI ตอบตัวเองด้วยโครงที่ดีกว่าเดิม
เทคนิค "ฝัง" การเขียน prompt ไว้ในตัว prompt เอง
สไลด์ 7 · ตัวอย่างจริง ①

การบ้านแง่ที่ 1–2: ภาพ AI และกราฟ

  • ภาพ (Higgsfield) "นักเรียนกำลังเรียนหนังสือด้วย AI" → ภาพทั่วไป
    เพิ่ม subject/แสง/องค์ประกอบ/ข้อจำกัด → ภาพตรงคอนเซปต์ใช้งานจริง
  • กราฟ (Desmos) "y=sin x" → เส้นเดียวไร้ความหมาย
    ระบุสมการ R(t)=A·e^(−t/S) + slider + เส้นวิกฤต y=50 → เครื่องมือสอนแบบโต้ตอบ
บทเรียน: ระบุ "เป้าหมายของผลงาน" ก่อนเสมอ
สไลด์ 8 · ตัวอย่างจริง ②

การบ้านแง่ที่ 3–4: Mermaid และ LaTeX

  • Mermaid "เขียน diagram การพัฒนา prompt" → 4 กล่องธรรมดา
    ระบุ subgraph 2 รอบ + classDef สี 3 ชุด → ไดอะแกรมสอนได้จริง
  • LaTeX "เขียนบทความ prompt engineering" → เทมเพลตอังกฤษว่างเปล่า
    ระบุ XeLaTeX+ฟอนต์ไทย+โครงเรื่อง+สมการ+ตาราง → บทความวิชาการ 2 หน้า
รู้ "คำสั่งเฉพาะ" ของเครื่องมือ = คุมผลลัพธ์ได้มากขึ้น
สไลด์ 9 · ตัวอย่างจริง ③

การบ้านแง่ที่ 5–6: สไลด์สรุปและเว็บไซต์

  • NotebookLM "สรุปไฟล์นี้เป็นสไลด์" → ได้ย่อหน้าข้อความ
    ระบุจำนวนหน้า+โครงเรื่อง+หน้าละ 3 bullet+คำศัพท์ตัวหนา → สไลด์ 10 หน้าพร้อมใช้
  • เว็บไซต์ "ทำเว็บสรุปงาน" → หน้ายาวเดียว
    ระบุเมนู 6 แท็บ + hash routing + ธีมเดียวทั้งชิ้น → เว็บไซต์แบบเลือกหมวดบน GitHub Pages
ทุกแง่ยืนยันแบบแผนเดียวกัน: zero-shot ได้ของทั่วไป — few-shot ได้ของของเรา
