Canva + Canva MCP
คู่มือตั้งค่าและใช้งานฉบับทำได้จริง

ครูแนะนำ Canva สำหรับ "การสร้างรูปด้วย AI" — ปกติเราสร้างงานใน Canva ด้วยมือเอง แต่ตอนนี้ Canva มี MCP Server ที่ให้ AI assistant (เช่น Claude, ChatGPT, Cursor) สั่งสร้าง/แก้ไข/ส่งออกงานในบัญชี Canva ของเราได้โดยตรง หมายความว่าเราเขียนพรอมป์ภาษาไทย แล้วได้ไฟล์งาน Canva จริงกลับมา — เหมาะกับการบ้านแง่นี้มาก

1) Canva MCP คืออะไร

MCP (Model Context Protocol) คือมาตรฐานเปิดที่เชื่อม AI assistant เข้ากับเครื่องมือภายนอก Canva เปิด MCP Server ที่ endpoint: https://mcp.canva.com/mcp (ใช้ OAuth เพื่อขอสิทธิ์เข้าบัญชี Canva ของคุณ) เมื่อเชื่อมต่อแล้ว AI จะทำสิ่งเหล่านี้แทนคุณได้:

  • สร้างดีไซน์จากข้อความ — "โปสเตอร์อบรม AI ธีมกลางคืน สีทอง-น้ำเงิน"
  • แก้ไขงานเดิม ด้วยภาษาธรรมชาติ + ค้นหาดีไซน์/หน้า/โฟลเดอร์/เทมเพลต
  • อัปโหลด asset เข้าคลัง และจัดการโฟลเดอร์
  • ส่งออกไฟล์ PDF / PNG / JPG / PPTX / MP4 และเปลี่ยนขนาดงาน (resize)
  • คอมเมนต์บนดีไซน์

2) สิ่งที่ต้องมีก่อน

องค์ประกอบรายละเอียด
บัญชี Canvaแผนฟรีใช้ฟีเจอร์หลักได้ (สร้าง/แก้/ค้นหา/ส่งออก) · Pro ถึง resize ได้ · Enterprise มี Brand Kit/Autofill
สิทธิ์ MCPสมัคร waitlist ที่ canva.dev ก่อน (Canva อนุมัติรายกรณี อาจใช้เวลาไม่กี่วัน)
AI ไคลเอนต์ที่รองรับ MCPClaude Desktop / Claude Code, ChatGPT ( connectors ), Cursor, VS Code, ZCode
Node.jsสำหรับ bridge ผ่าน npx mcp-remote (ถ้าไคลเอนต์ไม่รองรับ remote MCP ตรง ๆ)

3) ตั้งค่าทีละขั้น

ขั้น ① ขอสิทธิ์

  1. ไปที่ canva.dev/docs/mcp
  2. กรอก Waitlist form (ระบุ redirect URI ตามที่ไคลเอนต์กำหนด) แล้วรออีเมลอนุมัติ

ขั้น ② เพิ่ม server เข้าไคลเอนต์

ไคลเอนต์แบบ config mcpServers (Claude Desktop, Cursor, ZCode ฯลฯ):

{ "mcpServers": { "canva": { "command": "npx", "args": ["-y", "mcp-remote@latest", "https://mcp.canva.com/mcp"] } } }

VS Code (รูปแบบ servers ใน mcp.json):

{ "servers": { "Canva": { "type": "stdio", "command": "npx", "args": ["-y", "mcp-remote@latest", "https://mcp.canva.com/mcp"] } } }

ไคลเอนต์ที่รองรับ remote MCP ตรง — เพียงเพิ่ม URL https://mcp.canva.com/mcp หรือกดปุ่ม "Connect in Claude" ที่หน้า canva.com/ai-connector

ขั้น ③ ล็อกอินอนุญาต (ครั้งเดียว)

  1. รีสตาร์ทไคลเอนต์ แล้วสั่งงานอะไรก็ได้ เช่น "แสดงงาน Canva ล่าสุดของฉัน"
  2. จะมีหน้าต่าง OAuth ให้ล็อกอิน Canva แล้วกดอนุญาต
  3. เห็นข้อความ "authorization successful" = เชื่อมสำเร็จ

ขั้น ④ ทดสอบ

ผู้ใช้: ค้นหาเทมเพลตโปสเตอร์การศึกษาใน Canva ให้หน่อย AI: (เรียก canva search) เจอ 12 เทมเพลต ... ผู้ใช้: ใช้แบบแรก เปลี่ยนข้อความเป็น "อบรม Prompt Engineering เสาร์นี้ 9 โมง" แล้วส่งออก PNG ให้ฉัน

4) ตัวอย่างพรอมป์สำหรับการบ้านแง่ที่ 1 (แบบ Canva)

ทดลองใช้ zero-shot กับ few-shot กับ Canva MCP เหมือนที่ทำกับ Higgsfield:

// รอบแรก (zero-shot) — ผลลัพธ์: เทมเพลตทั่วไป ไม่ตรงธีม "ทำโปสเตอร์การบ้าน AI ให้หน่อย" // รอบสอง (few-shot) — หลังถาม-ตอบเรื่องธีม/สี/ขนาด/ข้อความ "สร้างโปสเตอร์ขนาด A4 แนวตั้ง ธีมกลางคืน พื้นน้ำเงินเข้ม #1d1b33 ตัวอักษรทอง #f5b942 หัวเรื่อง 'พลังของ Prompt' พาดหัวรอง 'จาก Zero-shot สู่ Few-shot' ใส่พื้นที่รูปภาพ 16:9 มุมซ้ายล่าง และช่องข้อความรายชื่อ 6 แง่มุมขวา แรงบันดาลใจโทนสีจากเว็บ prompt-lab ของฉัน แล้วส่งออกเป็น PNG"
เคล็ดลับ: ถ้าใช้ Canva Pro ให้เพิ่ม "ทำเวอร์ชัน 9:16 สำหรับ IG Story ด้วย" — การ resize คือฟีเจอร์เด่นที่ MCP เปิดให้เฉพาะแผน Pro

5) ข้อควรระวัง

  • สิทธิ์ตามแผนบัญชี: ฟรี = ฟีเจอร์หลัก, Pro = resize, Enterprise = Brand Kit/Autofill
  • rate limit มีตามที่ Canva กำหนด (ดูหน้า Tools and rate limits ในเอกสาร canva.dev)
  • AI กระทำในบัญชีจริงของคุณ — งานสำคัญให้กดยืนยัน tool call ทุกครั้ง (ไคลเอนต์ส่วนใหญ่ถามก่อนเสมอ)
  • อย่าส่งรหัสผ่านให้ใคร — OAuth เป็นวิธีเดียวที่ Canva ใช้ ไม่มี API key แบบวางใน config

6) ลิงก์ทางการ

  • หน้าผลิตภัณฑ์: canva.com/ai-connector
  • เอกสารนักพัฒนา: canva.dev/docs/mcp
  • วิธีเชื่อมต่อต่อไคลเอนต์: canva.com/help/mcp-agent-setup
